# 小儿垂钓

部编版小学语文二年级上册 · 语文园地三 · 日积月累

---

## 📖 古诗原文

**《小儿垂钓》**

[唐] 胡令能

```
péng tóu zhì zǐ xué chuí lún，
蓬 头 稚 子 学 垂 纶，

cè zuò méi tái cǎo yìng shēn。
侧 坐 莓 苔 草 映 身。

lù rén jiè wèn yáo zhāo shǒu，
路 人 借 问 摇 招 手，

pà dé yú jīng bù yìng rén。
怕 得 鱼 惊 不 应 人。
```

---

## 📝 词语注释

| 词语 | 意思 |
|------|------|
| **小儿** | 小孩子 |
| **垂钓** | 钓鱼 |
| **蓬头** | 头发乱蓬蓬的样子 |
| **稚子** | 年幼的孩子 |
| **垂纶** | 钓鱼（纶：钓鱼用的丝线） |
| **侧坐** | 侧身坐着 |
| **莓苔** | 草莓和青苔，这里指长满莓苔的地方 |
| **草映身** | 野草遮掩着身子 |
| **借问** | 请问，向人打听 |
| **遥招手** | 远远地招手示意 |
| **怕得** | 生怕、恐怕 |
| **鱼惊** | 把鱼吓跑了 |
| **不应人** | 不回应来人（怕惊鱼所以不说话） |

---

## 🌈 诗意理解

一个头发乱蓬蓬的小男孩，正在学习钓鱼。
他侧身坐在长满青苔的草地上，野草遮掩着他的身子。
有过路的人向他打听事情，他远远地摆摆手，示意不要出声。
原来他生怕声音太大把鱼吓跑了，所以不敢答应路人。

> **小结：** 这首诗描写了一个天真可爱、专心致志钓鱼的小朋友形象，画面生动，充满童趣。

---

## 👤 作者简介

**胡令能**（约 785—826 年），唐代诗人，河南郑州人。他的诗语言通俗易懂，描写日常小事生动有趣，尤其擅长写儿童题材，被称为"胡钉铰"（传说他年轻时是个补锅钉碗的工匠）。
